# Callie — локальный сайт

Это статический HTML/CSS/JavaScript шаблон. В архиве сохранены страницы и локальные ресурсы.

## Запуск в Windows

1. Распакуйте архив.
2. Откройте папку `callie`.
3. Самый простой способ — открыть `index.html` в браузере.
4. Рекомендуемый способ, если установлен Python: откройте PowerShell в папке `callie` и выполните:
   ```powershell
   python -m http.server 8000
   ```
   Если команда `python` не работает, попробуйте:
   ```powershell
   py -m http.server 8000
   ```
5. Откройте `http://localhost:8000`.

## Что включено в исправления

- Добавлен локальный JavaScript для проверки форм и отображения понятных статусов.
- Для HTML-страниц добавлен viewport для корректного отображения на мобильных устройствах, если его не было.
- Удалены случайно попавшие в архив HTML-страницы с ответом 404 и сторонние Cloudflare-скрипты аналитики.
- Ссылки и локальные ресурсы проверены на существование.

## Важное ограничение

Проект является фронтенд-шаблоном, а не готовым серверным приложением. Поиск сейчас ищет совпадения только на открытой странице. Контактная форма, комментарии и подписка проходят проверку полей, но не отправляют и не сохраняют данные. Для реальной отправки требуется backend/API либо сервис обработки форм. В архиве нет серверного кода или учётных данных такого сервиса.
